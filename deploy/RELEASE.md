musecanvas v1.0 · Windows 一键启动版

公开下载面向 Windows 10/11 x64 用户；公司 NAS 多人工作区属于特定部署方案。

下载 **musecanvas-windows-x64.zip** → 完整解压 → 双击 **start.cmd**。

- 内置 Node.js、Python、后端依赖和已构建的前端，无需 Docker、Git 或手动安装开发环境。
- 使用 Microsoft Edge / Google Chrome 打开本机工作区，无需注册。
- 在设置中绑定自己的 Muse Cookie，或配置 API Bridge、其它模型及本地 ComfyUI。
- 双击 stop.cmd 停止；数据和配置保存在本机，更新前请备份。
- 不包含任何个人账号、Cookie、API Key、公司域名或代理订阅。
- 程序免费下载；远端服务需要联网，账号、额度和费用由相应供应商决定。

SHA256SUMS 可用于校验 ZIP 完整性。解压包中的 README-Windows.txt 与 docs/使用说明.md 提供操作说明。
