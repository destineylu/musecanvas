# Mua Docker 部署

Mua 容器运行平台和前端。可通过 `MUA_UPSTREAM=bridge` 或 `MUA_UPSTREAM=muse2api` 选择独立运行的上游。

## 配置

复制本目录的 `.env.example` 为 `.env`。设置至少 32 字符的 `JWT_SECRET` 和至少 12 字符的初始管理员密码。已有实例保留原有登录签名密钥和数据目录。

- Bridge 模式登录后从「接入方式」添加远端节点和密钥。`server/data/bridges.json` 随数据卷持久化，节点及文件地址需要能从容器连接。
- 选择 muse2api 时，`MUSE_BASE` 填对应地址，`MUSE_KEY` 填引擎密钥。
- 从远程浏览器访问时设置 `PUBLIC_BASE` 为对外地址，媒体代理通过该地址提供文件。

## 运行

从本目录执行 `docker compose up -d --build`，从配置的 LAN 地址与 `8787` 端口访问。SQLite、上传和生成文件保存在 `./data/server`。同一数据目录运行一个 Mua 实例。多人共用同一个网关时，任务会由该网关统一排队。

## 排查

运行 `docker compose logs -f mua` 查看启动日志。登录后从「API Bridge」页检查模型。Windows 上编辑 `entrypoint.sh` 时保留 LF 换行。
