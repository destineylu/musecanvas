# musecanvas Docker 部署

多人使用请使用 [NAS 独立工作区部署](../nas/README.md)：每人一个内置 Muse 引擎的 musecanvas 容器，独立账号、数据库、Cookie、浏览器 profile 和模型密钥。不要把不同成员放进同一个实例或共享账号池。

本目录为单人单实例模板，启用 ACCESS_MODE=account。复制 .env.example 为 .env，填写 JWT_SECRET、ADMIN_EMAIL、ADMIN_PASSWORD；当前实例只允许 ADMIN_EMAIL 对应用户登录。HTTPS 设置 COOKIE_SECURE=1，内网 HTTP 调试改为 0。含其它邮箱用户的旧数据库禁止挂载到此模式。

docker compose up -d --build 启动后，登录、设置接入、绑定本人账号。本镜像在容器内启动私有 Muse 浏览器引擎，不再需要单独 muse2api 容器。MUSE_KEY 为各自的内置引擎密钥，engine 数据卷需要持久化。不要公开 muse2api 管理端口或浏览器调试端口。

数据在 ./data/server，首次密码仅用于初始化；之后在「设置 → 账号」修改。部署地址更改时核对 PUBLIC_BASE 与 Cookie 设置。
