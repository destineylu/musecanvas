# 外部模型接入

设置增加模型页，分别管理语言、图片、视频服务，保留 Muse 默认选项。配置包括名称、Base URL、密钥、模型 ID、协议、接口路径、比例映射及附加参数。默认选择立即持久化；画布显示当前选择，后端按任务提交时的模型配置绑定任务，对话与 AI 搭建共用语言选择。

支持 Chat Completions、Images generations/edits、OpenAI Videos multipart、兼容视频 JSON 任务接口。视频异步保存任务 ID 并查询结果；媒体存入现有素材目录，复用历史、版本及任务状态。协议不符报错，不默默退回 Muse，不丢弃参考图。

密钥只留服务器 data 中，不返回浏览器、不写任务历史；模型配置修改仅管理员允许。连通测试只读取模型列表，不发起收费媒体任务。跨域下载不携带供应商密钥。

验证：独立临时配置及 mock 服务，覆盖默认切换、语言请求、图片 Base64/参考图、视频轮询/恢复、密钥脱敏、非法配置和错误响应；构建前端并验证设置页面及画布模型显示。

用户追加：实现一键生成，注意并发关系。采用后端持久化依赖调度，默认并发 2、上限 3；执行前校验依赖与参考图，保留已完成素材。事务内绑定步骤与任务，防止重复提交；按全局及供应商上限派发，暂停/继续/停止后续任务，失败只阻断依赖分支。关闭页面不影响后台，重启续查已有任务 ID，提交结果未知时不自动重发。
