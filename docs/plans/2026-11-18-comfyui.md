# 本地 ComfyUI 接入

在图片 / 视频模型协议中加入 ComfyUI 工作流，支持 API JSON 文件导入及明确选择本机已保存工作流。界面列出节点输入，通过绑定把画布提示词、参考图、比例、宽高、种子、时长、帧数和帧率写入工作流，指定输出节点；导入只提供建议，不自动运行或切换默认。

后端使用 /upload/image、/prompt、/history、/queue、/view。持久化 prompt_id，重启仅查询，不重新提交。结果校验媒体格式后存入已有媒体目录，自动归档历史和素材库，复用画布及一键依赖执行。

同一个 ComfyUI 实例的图片 / 视频共享一个在途任务槽位，即使分别配置为两个模型也串行提交；不调用全局 interrupt，不干扰用户手工队列。停止流程仍然只停止后续派发。本机服务不可达明确报错，不切换远程或 Muse。

验证：mock ComfyUI 覆盖参数替换、参考图上传、图片/视频输出、缺少节点、失败与丢失任务、跨模型串行、重启不重复提交、UI 导入与选择、现有接口回归。初始本机 8188 未连通；用户启动后已连接 ComfyUI 0.28.0，并通过本机 SD1.5 实际生成图片、上传参考图、RepeatImageBatch/CreateVideo/SaveVideo 导出 MP4 后回传验证。后者是导出链路验证，不代表大型 AI 视频模型已实测。已配置 SD1.5 文生图 / 参考图模型供选择，保留原默认模型。
